# 資料模型: 圈圈叉叉遊戲

**Feature**: `001-tic-tac-toe` | **Date**: 2026-03-13

**語言要求**: 本文件 MUST 使用繁體中文。

## 實體定義

### 1. 棋盤格子（Cell）

| 欄位 | 型別 | 可能值 | 說明 |
|------|------|--------|------|
| `value` | `string \| null` | `'O'`、`'X'`、`null` | 格子內容；`null` 表示空格 |
| `index` | `number` | `0–8` | 格子在棋盤陣列中的位置（0=左上，8=右下） |

**驗證規則**:
- 已佔用格子（`value !== null`）不可再次落子。
- 遊戲結束後所有格子不可落子。

---

### 2. 棋盤（Board）

| 欄位 | 型別 | 說明 |
|------|------|------|
| `cells` | `Array<string \| null>` | 長度為 9 的陣列，索引 0–8 對應 3×3 棋盤位置（行優先） |

**棋盤索引對應**:
```
[0][1][2]
[3][4][5]
[6][7][8]
```

**勝利路徑（靜態常數）**:
```javascript
const WIN_LINES = [
  [0, 1, 2],  // 第一橫列
  [3, 4, 5],  // 第二橫列
  [6, 7, 8],  // 第三橫列
  [0, 3, 6],  // 第一縱行
  [1, 4, 7],  // 第二縱行
  [2, 5, 8],  // 第三縱行
  [0, 4, 8],  // 左上至右下對角線
  [2, 4, 6],  // 右上至左下對角線
];
```

---

### 3. 玩家（Player）

| 欄位 | 型別 | 可能值 | 說明 |
|------|------|--------|------|
| `symbol` | `string` | `'O'`、`'X'` | 玩家符號 |
| `name` | `string` | `'玩家一'`、`'玩家二'` | 顯示名稱 |

**規則**:
- 玩家一永遠先手，使用符號 `'O'`。
- 玩家二後手，使用符號 `'X'`。

---

### 4. 遊戲狀態（Game State）

| 欄位 | 型別 | 初始值 | 說明 |
|------|------|--------|------|
| `board` | `Array<string \| null>` | `[null, null, …, null]`（9 個 null） | 目前棋盤內容 |
| `currentPlayer` | `'O' \| 'X'` | `'O'` | 目前輪到哪位玩家 |
| `winner` | `'O' \| 'X' \| null` | `null` | 獲勝者符號；`null` 表示尚未結束或平局 |
| `isDraw` | `boolean` | `false` | 是否平局 |
| `gameOver` | `boolean` | `false` | 遊戲是否已結束（包含勝利與平局） |

---

## 狀態轉換

```
初始化
  ↓
[等待落子] ←──────────────────────────────┐
  │                                       │
  │ 玩家點擊空格                           │
  ↓                                       │
[落子] → 更新 board[index] = currentPlayer  │
  ↓                                       │
[勝利判定] → 有連線？→ [遊戲結束：獲勝]    │
  ↓（無連線）                              │
[平局判定] → 棋盤滿？→ [遊戲結束：平局]    │
  ↓（棋盤未滿）                            │
[輪次切換] → currentPlayer = 'O'↔'X'     │
  ↓                                       │
[等待落子] ──────────────────────────────→┘
  
[遊戲結束：獲勝 or 平局]
  ↓
  玩家點擊「重新開始」
  ↓
[初始化]（重置全部欄位）
```

---

## 驗證規則摘要

| 規則 ID | 條件 | 行為 |
|---------|------|------|
| V-001 | `board[index] !== null` | 忽略落子，不切換輪次 |
| V-002 | `gameOver === true` | 忽略落子 |
| V-003 | 三格相同且非 null | 設定 `winner`、`gameOver = true` |
| V-004 | `board` 全部非 null 且 `winner === null` | 設定 `isDraw = true`、`gameOver = true` |
| V-005 | 點擊「重新開始」 | 重置所有狀態至初始值 |
